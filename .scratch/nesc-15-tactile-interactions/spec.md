# NESC-15 — Tactile interactions + ambient audio

- **Status:** done
- **Labels:** ready-for-agent
- **Priority:** P2 (layer onto working structure — never before it)
- **Brief refs:** §6
- **Depends on:** NESC-14

## Summary
Make the exhibit **physical**: a dossier interface with tactile cursor physics, mechanical evidence cards, dissolving redactions, corkboard threads, and quiet optional analog audio.

## Why
§6 sets the bar: "extremely interactive — never a basic static site," benchmarked to Morgan Library archives + Resn-style interactive physics. Motion must feel like real materials, purposeful, never decoration.

## Scope / acceptance criteria
- [ ] Evidence cards **snap into place** with a soft mechanical lock.
- [ ] Witness transcripts have **redacted ink lines that dissolve on hover**.
- [ ] Connections view: threads strung across the dark corkboard (integrates NESC-12).
- [ ] Handwritten marginalia **glows faintly under the cursor**; tactile cursor physics (weight, drag, easing) rather than instant snaps.
- [ ] **Ambient analog audio** — paper slides, pen scratches, soft snaps — quiet, **optional, muted by default, never autoplay loudly**; a visible toggle. Assets bundled in `static/`.
- [ ] Drag-and-drop parchment sheets where it deepens the "handling an artifact" feeling.
- [ ] **`prefers-reduced-motion`** disables/reduces physics and animation; audio stays off by default; content remains fully usable without any of it.
- [ ] No CDNs; any physics helper is vendored into `static/`. Performance stays acceptable; physics never blocks reading content.

## Out of scope
- The base visual system (NESC-14).
- Broader a11y/perf audit (NESC-16).

## Notes
- Build incrementally; ship one convincing tactile interaction at a time rather than all at once.

## Status note (2026-08-22)
All tactile behaviours are in, and the audio that was deferred now ships:
seven clips generated by `tools/make_foley.py` (nothing to licence), plus a
looping ambient bed and cues for moving between sections and opening a file.

Two things worth knowing:
- The cursor lamp sits **behind** the parchment (`z-index: -1`). Painted over
  it, a lamp bright enough to see dropped `--ink-faint` labels below 4.5:1 at
  every visible alpha, so it lights the desk rather than filtering the file.
- The ambient bed restarts on each navigation, because this is a multi-page
  app. It fades in so the seam reads as a room re-entered. Continuous audio
  across pages would require client-side routing.
