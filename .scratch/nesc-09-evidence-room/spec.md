# NESC-09 — Evidence Room: four epistemic tiers

- **Status:** done
- **Labels:** ready-for-agent
- **Priority:** P1
- **Brief refs:** §7, §11
- **Depends on:** NESC-03, NESC-04

## Summary
The Evidence Room is where the aesthetic becomes real research: exhibits sorted into four **always-distinguished** epistemic tiers, each backed by a real citation.

## Why
§7/§11: separate **what we know · what the evidence suggests · what researchers disagree about · what we don't know.** Reaching UNKNOWN is the point, not a weakness.

## Scope / acceptance criteria
- [ ] Evidence Room renders the four tiers as distinct, clearly-labelled zones; the visual language makes the tier obvious at a glance.
- [ ] Each exhibit shows its claim + a **reference card** (NESC-04) tracing to a real paper. No uncited factual claims.
- [ ] The **UNKNOWN** tier is treated as a first-class exhibit (faded evidence-red), not an afterthought.
- [ ] Example Memory exhibits present: Patient H.M. (know/what-we-know), Loftus false memory (evidence-suggests / disagreement), reconsolidation (evidence-suggests).
- [ ] Data comes from the concept `evidence_room` structure (NESC-03).

## Out of scope
- Citation primitive itself (NESC-04).
- Authoring evidence for concepts beyond Memory.

## Notes
- This is the epistemic core — correctness of tier labelling matters more than decoration.
